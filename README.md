# Rock, Paper, Scissors

A simple Rock, Paper, Scissors game built with **HTML, CSS and JavaScript**.

The player competes against the computer by choosing rock, paper, or scissors. The game determines the winner of each round and keeps track of the score.

## Features

* Play against the computer.
* Choose between rock, paper, and scissors.
* Random computer selection.
* Display the result of each round.
* Track wins, losses, and draws.
* Update the score dynamically.

## Technologies

* HTML5
* CSS3
* JavaScript

## How to Play

1. Choose rock, paper, or scissors.
2. The computer randomly selects its move.
3. The game compares both choices.
4. The result is displayed on the screen.
5. The score is updated after each round.

## Game Rules

* Rock beats scissors.
* Scissors beats paper.
* Paper beats rock.
* Matching choices result in a draw.
